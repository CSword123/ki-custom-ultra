Put your own copy of Killer Instinct here: the MAME set "kinst".

  kinst.zip    the ROMs (ki-l15d.u98 and the sound ROMs u10-l1 ... u36-l1)
  kinst.chd    the hard disk (kinst/kinst.chd works too)

ki-custom-ultra checks every file against the original dumps (the v1.5d
U98 must be unmodified) and unpacks them once into data/. It does not
work without them.
